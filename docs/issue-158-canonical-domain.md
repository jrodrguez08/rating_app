# Issue #158: canonical public origin

The canonical production origin is `https://www.futratecr.com`. This focused change starts at master `413c7a5` (merged #156 and #157), updates the obsolete fallback and replaces an indirect environment lookup. The audit's missing production setting plus the obsolete fallback explain the observed old-host URLs; the later environment addition requires a new build. Current URLs originate on the server and cross into browser controls as props. Next.js only inlines direct `process.env.NEXT_PUBLIC_SITE_URL` references into browser bundles, so the direct lookup also makes this shared configuration safe for browser consumers; the indirect lookup is not a separately proven cause of the production incident. Both the explicit configuration and fallback reach the real entry points. No URL is derived from the request, forwarded host or Vercel Preview host.

The only retained production legacy-host references in this change are the explicit audit/alias documentation. Test `.test`/`.example` origins intentionally exercise configuration or adversarial hosts; provider portrait, WhatsApp, Resend and Firebase endpoints have their own service domains. Historical draft and old global-path rollout prose is retained as historical context, not an instruction to generate old-host URLs. No alias redirect, Firebase setting, Vercel setting, secret, voting record, result, window or authentication policy is changed.

## Regression evidence

- Config and decoded WhatsApp tests cover both clubs, encoded IDs, explicit/fallback origins and Preview-host independence.
- Browser regression runs against the real local server and hydrated Home, result sharing/copy, canonical/Open Graph/Twitter metadata, locale/version/page image links and Studio overlay for both clubs and locales. The request host is localhost, distinct from the canonical origin. `E2E_SITE_URL` changes the test server configuration; a blank (empty or whitespace) value exercises the production fallback.
- Image entry-point regression inspects the actual React artwork handed to ImageResponse for each club and each origin mode, using hostile request/forwarded/Preview hosts. Existing real PNG tests and browser image requests verify rendering and dimensions independently.
- Notification regression invokes the application service through Resend with a mocked test-only sender for both clubs. It verifies configured canonical links and successful linkless delivery with missing/invalid configuration. No real mail is sent.

See the [production runbook rollout gate](../PRODUCTION_RUNBOOK.md#issue-158-canonical-domain-rollout-gate). A passing local suite or fresh Preview does not complete production acceptance; #158 stays open until the separately authorized deployment and live verification.
